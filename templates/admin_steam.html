Family library access token

Steam Family shared games need a logged-in session token, which is separate from the API key and expires after a few hours or days. While it is valid, shared games are merged into the library. When it expires, the library falls back to your own games automatically. The stored token is never displayed.

Hidden games

Steam does not expose which games you hid in the client, so pick them here. Checked games are removed from the public library page and from all totals.
